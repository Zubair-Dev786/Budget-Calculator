# Budget Tracker 💰

A simple Budget Tracker built with **HTML, CSS and JavaScript**.

## 🚀 Features

* Set monthly income
* Add and delete expenses
* Expense categories
* Total expenses calculation
* Remaining balance
* Highest and lowest expense
* Budget status
* LocalStorage support

## 🛠️ Technologies Used

* HTML
* CSS
* JavaScript
* SweetAlert2
